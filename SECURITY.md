# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through [GitHub private vulnerability reporting](https://github.com/romainGouraud/vidora/security/advisories/new), or by email to support@getvidora.com with "Security" in the subject.

Please include the Vidora version, the browser, and the steps to reproduce. You will get a first answer within a few days. Fixes ship through the Chrome Web Store; we will credit you in the release notes if you wish.

## Supported versions

Only the latest version published on the Chrome Web Store receives fixes. Chrome updates extensions automatically.

## Scope

In scope: the Vidora extension and getvidora.com (including its online tools).
Out of scope: reports that require a compromised computer or browser, and requests to bypass DRM, which Vidora refuses by design.
