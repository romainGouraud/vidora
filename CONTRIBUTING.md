# Contributing to Vidora

Thank you for helping. Vidora's source code is not public, but the community shapes the product in very concrete ways.

## 1. Report a site that fails

This is the most useful contribution. Use the [site request form](https://github.com/romainGouraud/vidora/issues/new?template=site-request.yml). A good report has:

- the domain, and a public example page if one exists;
- what Vidora does (no video found, download fails, no sound, wrong video);
- whether you pressed play before downloading and whether you are logged in.

If the site is already reported, add a 👍 to the existing issue instead of opening a new one: the number of 👍 sets the order of the work.

## 2. Report a bug

Use the [bug report form](https://github.com/romainGouraud/vidora/issues/new?template=bug-report.yml), and if you can, also click **Report a problem** in the extension: the private report carries the technical details that the public issue should not.

## 3. Suggest and vote for features

Post in [Ideas](https://github.com/romainGouraud/vidora/discussions/categories/ideas), one idea per post, with the problem it solves for you. Vote with 👍 on the ideas you want first. The [roadmap](ROADMAP.md) is updated from these votes.

## 4. Improve a translation

Vidora is translated into 30 languages. If a sentence in your language is wrong, unnatural or cut off, open an issue with:

- the language;
- where you saw it (popup, settings, an error message) and a screenshot of that part only;
- the current text and your suggested text.

## 5. Help other users

Answer questions in [Q&A](https://github.com/romainGouraud/vidora/discussions/categories/q-a). When an answer solves a question, the author can mark it as the answer.

## What is out of scope

Requests to support YouTube, or to bypass DRM or any other copy protection, are closed without discussion. Only download videos you have the right to keep.

## Privacy

Everything here is public. Never post private course links, links containing tokens (`token=`, `signature=`, `Policy=`, `Key-Pair-Id=`), cookies, emails or screenshots showing your account. When more is needed, we will ask you to send it privately.

## Code of conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
